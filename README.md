# 🎬 Netflix Clone Website

A responsive **Netflix Clone UI** built using pure **HTML and CSS**.  
This project recreates the front-end layout and styling of Netflix for learning and practice purposes.

---

## 🚀 Features

- 🎥 Netflix-inspired homepage UI
- 📱 Responsive layout for different screen sizes
- 🎨 Clean and modern design using CSS
- 🖼️ Image assets and favicon support
- ⚡ Fast loading static website
- 🌐 No backend required

---

## 🧰 Technology Stack

- **HTML5**
- **CSS3**
- **Static Assets (Images & Icons)**

---

## 📂 Project Structure

```
NETFLIX_CLONE/
├── assets/          # Images and media assets
├── favicon.ico      # Website favicon
├── index.html       # Main HTML page
├── style.css        # CSS styling
└── README.md        # Project documentation
```

---

## ▶️ How to Run

### ✅ Method 1: Open Directly

1. Download or clone the repository.
2. Open `index.html` in any web browser.

---

### ✅ Method 2: Using Live Server (Recommended)

If you are using VS Code:

1. Install **Live Server Extension**.
2. Right-click `index.html`.
3. Click **Open with Live Server**.
